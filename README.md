# SKILLS PARA LLM
Lista de skills que desenvolvi ou fiz curadoria e apliquei alterações para melhor se adequar ao meu fluxo e necessidades. Todas são genéricas, servem para qualquer agente LLM (foram modificadas para isso). 

## MCP Builder (Pendente de melhoria)
Skill criada para criação de novos MCPs. TODO: Mudar para colocar regras para MCP em .NET também

## Ralph Loop PRD Generator
Skill criada para criar novos arquivos PRD no padrão do meu projeto de Ralph Loop CLI https://github.com/rodrigojager/ralph

## Superbuild
Skill criada para gerar prompts de execução rigorosos para entregáveis complexos, com critérios explícitos, validação independente, ciclos de correção e evidências reproduzíveis. É uma skill própria e separada do Gauntlet Loop.

## Skill Creator
Skill criada para criar novas skills. Sempre que for criar uma skill, usar essa como contexto para geração.
